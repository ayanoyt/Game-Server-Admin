# Game-Server-Admin
Painel web para administração de servidores de jogos, desenvolvido com React, Node.js, Express, tRPC e SQLite. Possui autenticação OAuth, controle de acesso por funções, monitoramento em tempo real, gerenciamento de servidores e usuários, logs de atividades, backups, documentação da API e interface responsiva com design neon-noir.
